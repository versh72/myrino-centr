## Что это

Мурино Центр — интернет-станция выдуманного явления **Меллстройность**. Одностраничный
сайт без фреймворков и сборки: адаптивная вёрстка, плеер, рекомендации, переводчик
и форма обратной связи.

| Раздел | Что внутри |
|---|---|
| **Станция** | 290 треков MellFM, круглосуточный эфир, плеер с лайками и дизлайками |
| **Меллна** | Рекомендации внутри плеера: «Моя волна», «Похожие», «Лайки» |
| **Атлас сезонов** | Шесть сезонов, связанных в графу, 12 персонажей |
| **Портал звуков** | 101 мемная реплика, загрузка своих файлов, свои станции |
| **Переводчик** | Перевод русского языка в мурино, 423 существительных |
| **Обратная связь** | Заявки уходят в Issues этого репозитория |

## Язык Меллстройности

К существительным прирастает окончание `-ость`, к незнакомым словам на гласную — `-ность`.

| обычный | мурино | | обычный | мурино |
|---|---|---|---|---|
| друг | **друн** | | это | **этость** |
| компьютер | **компьютерость** | | курица | **курицаность** |
| гей | **гейность** | | музей | **музейность** |

Не трогаются глаголы, прилагательные и служебные слова: `купить`, `красивый`,
`очень`, `потому что`. Есть диалект Витька — `друг → друц`.

## Что внутри репозитория

```
index.html              собранный сайт (CSS и JS сжаты)
sounds-data.js          290 треков и 101 реплика
img/                    иконки, превью для соцсетей, портреты
robots.txt              правила для поисковиков
sitemap.xml             карта сайта
manifest.webmanifest    манифест для мобильных
llms.txt                краткое описание для ИИ-краулеров
```

Разметка `schema.org`: `WebSite`, `Organization`, `DefinedTerm`,
`MusicBroadcastingService`, `FAQPage` — чтобы сайт находился и в поиске,
и в ответах языковых моделей.

## Панель «Закулисье»

Скрытая служебная панель: тройной клик по слову «Закулисье» в подвале.
Пароль хранится в виде SHA-256 хеша, а не открытым текстом.

## Обратная связь

Заявки с формы отправляются через публичный API GitHub в Issues этого репозитория
и показываются в панели «Закулисье». Репозиторий открытый, поэтому заявки видны всем —
это сделано осознанно, как публичная доска предложений.
